# Utility Bill Tracker

I want ot create an offline app. It will be similar calculater but not all calculater. it will be use for Gas, electric and water money calculation. First, we enter the home page and appears 3 buttons Gaz, tok and Suw (language will be english, russian and turkmen, it will be sk first when user fist download and open first time), then, afteropening one of them, it will appear 2 input area which will be for: previous number of machine(which counts the electric, gas or water) and present time is number, then it will 2 buttons under these: Yatda sakla(Save) and hasapla(calculate).  When click to calculate, it will show how much something spent and the price(price can be changeble onthe setting bar). When click save, it will store the record of how many somehting used, money and date of the calculation. Settings bar will have be nigt and light mod, lang change, price change. Also make an button for history of the record.
